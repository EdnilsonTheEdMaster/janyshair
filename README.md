# Janys Hair

Loja virtual demonstrativa de cabelos afro, feita com HTML, CSS e JavaScript puro.

## Páginas

- `index.html`: apresentação da loja e destaque da semana.
- `cabelos.html`: catálogo de cabelos com fotos, descrições e especificações.
- `sobre.html`: história e propósito da marca.
- `carrinho.html`: produtos selecionados, especificações, quantidades e resumo.

## Como visualizar

Abra `index.html` no navegador. Para testar em um servidor local com Python, execute `python -m http.server 8000` na pasta do projeto e acesse `http://localhost:8000`.

O carrinho é salvo no armazenamento local do navegador. Esta versão não integra pagamento ou envio de pedidos. Os preços dos produtos ainda precisam ser informados; enquanto isso, aparecem como "Consulte".

## Fotos dos produtos

Salve as fotos em formato JPG na pasta `img`, com estes nomes:

- `img/agata.jpg`
- `img/livre.jpg`
- `img/katrine.jpg`

Use esses mesmos nomes e a extensão `.jpg` para que as fotos apareçam no catálogo, na página inicial e no carrinho.
